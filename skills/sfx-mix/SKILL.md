# sfx-mix

## Mix (bed + voice)

```bash
scripts/mix_one.sh <slug>              # optional 2nd arg: chord frequencies
# writes episodes/<slug>/bed.wav and remotion/public/<slug>.wav
```

The bed is a synthesized low chord + pink noise, faded in/out, mixed about **9 dB under** the voice, then limited. Voice should already be loudnormed to −14 LUFS (`skills/voice`).

Finished-mix targets (enforced in QA): integrated **−15.5 to −13 LUFS**, true peak **≤ −1 dBTP**.

## Cues in the composition

Prepared, level-matched wavs live in `remotion/public/sfx/` (`volume=1` is about 12–14 dB under the voice):

| file | when to use it |
|---|---|
| `whoosh.wav` | every world-move transition |
| `pop.wav` / `tick.wav` | a label, counter, or object lands |
| `click.wav` | small UI / gear tick |
| `confirm.wav` | success |
| `error.wav` / `glitch.wav` / `thud.wav` / `clank.wav` | failure, impact |
| `riser.wav` | into the outro card |
| `sting.wav` | on the line "That's the mechanism." |

Place cues with the brand `Sfx` helper so they fire on a frame that matches a visible event.

## Levels and density

- Median SFX peak **10–16 dB under** the voice (400 ms RMS). Nothing closer than **8 dB**.
- Aim for a cue on each transition and each label landing. Do not spray more than about two hits per second and do not mask consonants.
- QA renders separate stems (`--props '{"stem":"sfx"}'` / `"voice"`) to measure this. If a cue is too hot, lower it or shorten it — do not raise the voice above the loudness target.

## Licensing

- Kenney packs in `sfx/kenney/` are **CC0 1.0** (`License.txt` in each pack).
- Original synths in `sfx/synth/` (whoosh, riser, sting, tick) are **CC0**, generated by `scripts/synth_sfx.py`.
- Mapping of prepared files: `sfx/CREDITS.csv`.
- To add a new cue: drop a licensed source into `sfx/`, run `scripts/prep_sfx.py` (normalises a 400 ms window), copy into `remotion/public/sfx/`, and append a row to `CREDITS.csv`. No unlicensed scrapes.

Audio products (`bed.wav`, `narration*.wav`, `remotion/public/<slug>.wav`) are gitignored and rebuilt.

## Round 4 rules
- Onset density gate is 1.2–1.5/s (qa.py A3b). Trim order: micro-ticks (`EpisodeShell microGap`), then tick runs, then duplicate whooshes on camera moves.
- If the median SFX gap is > 16 dB under the voice, raise soft cue volumes (0.85–0.95) or widen `microGap` rather than adding cues.
- papercut-explainer cues (swish, whip, cut, glint, stamp, count, pop3, micro) are MIT; see `sfx/CREDITS.csv`.
