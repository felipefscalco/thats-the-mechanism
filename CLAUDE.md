# CLAUDE.md

This repository is LLM-agnostic. **Read [`AGENTS.md`](AGENTS.md) first** and follow it as the canonical instruction set. Lessons and critic rules follow the [enforcement hierarchy: code over prose](AGENTS.md#enforcement-hierarchy-code-over-prose): a QA gate that blocks the render, then a Remotion primitive that makes the error impossible, and prose in `docs/STYLE_RULES.md` only for subjective craft.

Project skills (Agent Skills format) are in `skills/`. Remotion's official skills, if present after setup, are in `remotion/.agents/skills/`.

Do not publish or upload videos. Human approval is required for the angle, the script, and the final cut.
